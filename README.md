# Hari Krishna Talikota - Official Website

A modern, responsive website for Hari Krishna Talikota, iTDP Telangana State President and Board Member of Sri Kanaka Durga Devasthanam.

## 🚀 Tech Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, AOS
- **Routing**: React Router DOM
- **SEO**: React Helmet Async
- **Icons**: React Icons

## ✨ Features

- ⚡ Lightning-fast performance with Vite
- 📱 Fully responsive design (mobile-first)
- 🎨 Modern UI/UX with smooth animations
- 🔍 Comprehensive SEO optimization
- 🌐 Geo-tagged for local search
- ♿ Accessibility compliant (WCAG 2.1 AA)
- 🎯 Interactive components
- 📊 Structured data (Schema.org)
- 🎭 Smooth page transitions
- 🖼️ Optimized images
- 📈 Performance optimized

## 📦 Installation

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```

## 🎨 Design System

### Colors
- **TDP Yellow**: #FFD700 (Primary party color)
- **TDP Green**: #228B22 (Secondary party color)
- **Primary Blue**: #1E3A8A (Authority and trust)
- **Accent Orange**: #F97316 (Call-to-action)

### Typography
- **Headings**: Montserrat (Bold, Semi-bold)
- **Body**: Open Sans (Regular, Medium)
